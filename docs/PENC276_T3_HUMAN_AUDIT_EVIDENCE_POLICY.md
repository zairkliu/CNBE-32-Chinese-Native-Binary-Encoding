# PENC276 T3 人工审核证据政策

## 定位

PENC_169 至 PENC_276 是探索性编码研究批次。该批次的最终项目基线是已记录的人工审核，
而不是任一单独外部数据源。

## 证据角色

| 证据 | 角色 | 不可作出的解释 |
|---|---|---|
| 人工审核 | 最终项目基线；记录结构与拆解的项目裁决 | 不自动成为国家标准结论 |
| 国家语言文字规范 | 对齐目标、约束与解释依据 | 不以缺失的逐字机器可读数据替代人审 |
| Unihan | Unicode/康熙口径的交叉参考 | 不作为本探索批次的金标准 |
| ZDIC | 网络交叉参考、差异发现与复核线索 | 不作为国家标准或自动写入依据 |

## 运行规则

1. 外部来源与人审一致时，记录为对齐证据；
2. 外部来源与人审不一致或缺失时，保留差异，不静默覆盖人审；
3. 人审尚未给出部首或笔画裁决时，不从外部来源自动补写；
4. CNBE 候选、源表和 SQLite 写入仍要求单独的字段齐备检查与写入授权；
5. 所有公开产物均称为 `human_reviewed_project_evidence` 或探索性结果，禁止称为
   `national_standard` 或“金标准”。
