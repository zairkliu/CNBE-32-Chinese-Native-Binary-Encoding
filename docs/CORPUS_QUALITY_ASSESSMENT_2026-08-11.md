# 出版物中文语料库质量评估

日期：2026-08-11
依据：1281 本 MD 清洗 manifest + 1237 本编码报告

## 一、总体结论

语料体量真实、中文主体明确，适合作为 CNBE 结构预训练语料；但不是
“纯净中文码流”，存在三类需要处理的噪音：非中文字符、套装/合集内容
重叠、少量转换损坏文件。

## 六、CNBE 覆盖率

整体覆盖率 78.37%。未覆盖字符主要是中文标点、西文字母、数字和少量
生僻字，不是“中文覆盖率”。结构任务前应补 CJK-only 覆盖率统计。

## 七、风险清单

1. code 0 占 21.6%，Structure-MLM 前必须过滤或单独标注；
2. 套装/合集内容重叠会放大 token 数，建议内容级去重；
3. 少数转换文件损坏（9 本空输出、醉文明仅 18 字符）需人工复核；
4. 技术书低中文占比会增加码流噪音，可拆成独立子集。

## 八、建议

1. 建立“核心中文子集”：中文占比 ≥70% 的 1,075 本；
2. 技术书单独作为“技术子集”，不进结构预训练主语料；
3. 对套装/合集做 minhash 内容去重；
4. 输出 CJK-only 覆盖率；
5. 按类别抽样人工检查转换质量。
