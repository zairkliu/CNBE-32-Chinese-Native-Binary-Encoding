## 二、挂载与启动

推荐挂载：

| 上传目录 | 容器路径 |
|---|---|
| `code` | `/app` |
| `data` | `/data/cnbe` |
| `assets` | `/app/assets` |
| `output` | `/output` |

启动：

```bash
bash /app/scnet_startup_dcu2.sh --smoke-only
bash /app/scnet_startup_dcu2.sh
```

## 三、训练顺序

1. smoke 验证 DCU 与数据挂载；
2. P0 控制训练：Dense same-config、Unicode same-config；
3. 出版物纯文本完成清洗与 CNBE 编码后，合并进既有 24M 码流；
4. 重建 vocab 与 mapping，重新打包上传；
5. 在 2 卡 BW 上跑合并语料的 MoE 训练与对照。

## 四之三、可直接上传的打包（2026-08-10）

```text
D:\训练语料\scnet_upload_package_MERGED_DCU.tar.gz   # 约 1.5GB
```

包内含：

- 代码：`code/`（train_scnet / train_distributed / build_unicode_dataset 等）
- 数据：`data/`（1244 个 .cnbe，约 2.18GB）
- 清洗文本：`data_src/`（7 个既有 chars.txt + 1237 本清洗文本）
- assets：`assets/`（merged vocab / mapping_128 / mapping_256）
- 配置：`config/`（merged 128 / 256 / Dense / Unicode）
- 启动：`scnet_startup_dcu2.sh`

上传后：

```bash
tar -xzf scnet_upload_package_MERGED_DCU.tar.gz
export CNBE_MOE_ROOT=/root/scnet_upload_package_MERGED_DCU/code
export CNBE_DATA_DIR=/root/scnet_upload_package_MERGED_DCU/data
export CNBE_OUTPUT_DIR=/root/scnet_upload_package_MERGED_DCU/output
export CNBE_MOE_CONFIG=scnet_moe_config_merged_dcu2.yaml
bash /root/scnet_upload_package_MERGED_DCU/scnet_startup_dcu2.sh --smoke-only
bash /root/scnet_upload_package_MERGED_DCU/scnet_startup_dcu2.sh
```

逐本编码：

```bash
python scripts_src/encode_corpus_fast.py \
  work/corpus_publications_clean/<book>.txt \
  work/corpus_publications_clean/<book>.cnbe \
  --db repo/data/cnbe32.db
```

合并既有 7 语料 + 新出版物，重建 vocab/mapping：

```bash
python scnet_upload_package/code/scripts/build_data_assets.py \
  --cnbe-paths \
    scnet_upload_package/data/zzjh_294.cnbe \
    scnet_upload_package/data/luxun_18.cnbe \
    scnet_upload_package/data/agatha.cnbe \
    scnet_upload_package/data/csbook.cnbe \
    scnet_upload_package/data/jinyong.cnbe \
    scnet_upload_package/data/caixin.cnbe \
    scnet_upload_package/data/sushi.cnbe \
    work/corpus_publications_clean/*.cnbe \
  --output-dir work/corpus_assets_merged \
  --experts 128 256
```

覆盖门槛：编码后单本覆盖率低于 99% 时，先按未知字复核并补录 CNBE，
再进入训练包。
