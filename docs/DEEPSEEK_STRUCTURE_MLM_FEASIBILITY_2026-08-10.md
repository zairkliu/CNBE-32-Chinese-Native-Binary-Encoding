# DeepSeek 三步法可行性评估

日期：2026-08-10
对象：Structure-MLM、结构伪度量对比学习、256 结构路由 MoE

## 一、总判断

三个方向不是“不可行”，而是**顺序和前提需要修正**：

1. Structure-MLM 值得做，但先要把数据里的 code 0 噪音处理好；
2. 对比学习不能直接拿现有伪度量当监督，需要先修度量本身；
3. “按结构路由”其实已经是当前硬路由在做的事，不需要先上 256 专家
   去验证；128 专家在合并语料上先跑通才是下一步。

DeepSeek 方案最大的问题：**跳过了 Dense/Unicode 对照，直接推 256 专家**，
这与我们已经写进 skill 的边界冲突。

## 二、环境事实修正

| 项目 | DeepSeek 说法 | 实际 |
|---|---|---|
| 显存 | 双卡 128GB | 工具面板显示总显存 256GB |
| 语料 | “2.08GB 纯净码流” | 2.08GB 码流中约 21.6% 是 code 0（标点/西文/未知） |
| 结构路由 | 需要新增 Gate 辅助 Loss | 当前硬路由已经按 `(radix, struct, strokes)` 分发 |
| 对照 | 未提 | 我们坚持先跑 Dense / Unicode 对照 |

## 三、逐条评估

### 1. Structure-MLM

可行性：中高。当前模型已有 radix/struct/strokes 字段头，改造为
“15% mask + 预测字段三元组”是自然扩展。

风险：

- code 0 占 21.6%，如果照单全收，模型会学“所有噪音都是 0”；
- 只预测字段而不预测 idx，任务可能偏简单，radix/struct 提升不一定
  代表结构理解；
- 需要先做小规模消融，不能直接 5.44 亿全量跑。

修改建议：新增 `task_type: structure_mlm`、`mask_ratio: 0.15`，
先过滤或单独标注 code 0，再在 5,000 万 token 子集上验证。

### 2. 伪度量对比学习

可行性：中，但监督信号需要先修。

风险：

- 当前 `field_weighted_distance` 存在“不同字距离为 0”的反向碰撞
  （数据库自验已发现 4 个），直接当正负样本标签会把缺陷固化；
- 缺少形近字评测集，t-SNE 图不能作为结论，只能作为可视化；
- “国际没有开源模型能做到”属于不可验证宣传，论文里不能这么写。

修改建议：

1. 先建 500-1000 对形近字评测集（人工审核）；
2. 修度量：把 index/ext 纳入距离，或建立等价类表解决碰撞；
3. 再做对比学习消融，确认比“无对比学习基线”有效。

### 3. 256 结构路由 MoE

可行性：低优先级。当前硬路由就是结构路由，先证明 128 在 5.44 亿
语料上的收益，再谈 256。

风险：

- 256 专家在 24M 语料上已被复盘否定；
- 合并语料更大，但“更大专家数”仍不是第一变量；
- radix 准确率 20.23% 是旧 24M next-code 任务的指标，不能直接拿来
  与 Structure-MLM 的 radix 准确率比较。

修改建议：128 专家 1 epoch 跑完后再决定 256；新增 `radix_consistency`
指标衡量“同一部首是否进入同一专家”，而不是只盯 Gini。

## 四、修订后的执行顺序

| 顺序 | 任务 | 前置条件 |
|---|---|---|
| P0 | 合并语料 Dense / Unicode 对照 | 数据包已就绪 |
| P1 | Structure-MLM 代码 + 小规模消融 | 处理 code 0 与字段评估集 |
| P2 | 128 专家合并语料 1 epoch | P1 通过 |
| P3 | 度量修正 + 形近字评测集 | 数学实验 |
| P4 | 对比学习消融 | P3 通过 |
| P5 | 256 专家 | P2 与 P4 都有正向证据 |

## 五、算力估计

128 专家、d_model=1024、2 卡 BW：

- 每步 tokens：2 × 8 × 8 × 256 = 32,768
- 1 epoch 步数：544M / 32,768 ≈ 16,600
- 按 0.5-1.5 steps/s 估算：3-9 小时
- 实际以 smoke 实测为准，不建议直接排 2-3 天

## 六、结论

DeepSeek 的“结构认知模型”愿景与我们一致，但执行方案必须改成：

```text
数据清洗 -> 对照 -> 128 专家 -> 结构 MLM 消融 -> 度量修正 ->
对比学习消融 -> 再谈 256
```

不跳过对照、不拿宣传话术当证据、不把 21.6% 噪音说成纯净码流。
