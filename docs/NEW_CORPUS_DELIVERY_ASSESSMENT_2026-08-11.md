# 新交付语料库评估：CNBE中文出版物非重复语料库

日期：2026-08-11
结论：可作为下一阶段语料源，但需先做跨批次去重、CNBE 覆盖率和
子集抽样，不能直接全量训练。

## 一、交付内容

| 项 | 值 |
|---|---:|
| zip | `CNBE中文出版物非重复语料库.zip`，约 10.4GB |
| 文件数 | 13,098 本 TXT |
| 总字符 | 5,327,577,791 |
| 中文字符 | 4,369,220,443 |
| 批次 | v2 1281 / v2.1 5229 / v2.2 6588 |
| 数据库 | `数据库/cnbe_corpus.db` |
| 分类 | 14 类，含经济管理/社会科学/文学小说/历史等 |
| 古籍包 | `殆知阁古籍精校_独立包.zip`（约 190MB） |

## 二、抽样审计

每个批次随机抽 10 本，检查前 2 万字符：

| 批次 | 中文占比区间 | 版权/ISBN/总目录等命中 |
|---|---|---:|
| v2 | 0.43-0.87 | 0/10 |
| v2.1 | 0.78-0.90 | 0/10 |
| v2.2 | 0.54-0.88 | 0/10 |

抽样文本整体干净，无明显版权页残留。

## 三、风险

1. **跨批次重复风险**

   - `02_v2.1非重复/v2.1_金融帝国_美国金融霸权的来源和基础_迈克尔_赫德森.txt`
   - `03_v2.2非重复/v2.2_金融帝国_美国金融霸权的来源和基础_-_迈克尔_赫德森.txt`

   同一本书出现在两个批次，说明“非重复”可能只保证批次内去重，
   不能保证批次间无重叠。需要做内容级跨批次 minhash/hash 去重。

2. **清洗残留**

   - 个别文件开头仍有作者行，如 `[英]查理·汉格森`；
   - 文件名中带作者/出版社，不影响正文，但目录统计会误导。

3. **全量训练不可行**

   5.33B 字符按 4096 token/step、1.93 steps/s 估算：

   - 1 epoch ≈ 130 万步；
   - 约 670 小时（约 28 天）；
   - 双卡 BW 无法直接全量训练。

## 四、建议的下一步实验

1. 跨批次内容级去重（v2.1/v2.2 重点）；
2. 全量 TXT 跑 CNBE 编码与 CJK-only 覆盖率；
3. 构建核心中文子集（中文占比 ≥70%）；
4. 抽样 300-500M token 作为下一轮实验语料；
5. 顺序不变：Dense/Unicode 对照 -> 128 专家 -> 结构调整。

## 五、古籍包

`殆知阁古籍精校_独立包.zip` 适合作为古籍子集：

- 包含全唐文等精校文本；
- 繁体/生僻字可能超出 CNBE32 覆盖，需单独评估；
- 建议与白话语料分开编码和训练。

## 六、结论

可以作为下一阶段的语料源，但不能直接当“下一轮训练集”：

```text
去重 -> 编码 -> 覆盖率 -> 核心子集 -> 300-500M token 抽样 -> 对照实验
```
