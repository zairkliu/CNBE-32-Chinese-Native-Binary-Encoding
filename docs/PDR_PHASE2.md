## 2. 第二阶段定位

第一阶段回答"数据现状是什么"（诊断）；第二阶段回答"**可信数据层如何建成并被外部验证**"（治疗 + 验证）。

总目标（对应 v1.1.0 发版）：

> 把 8105 标准轨建成一个语义冻结、专家裁决闭环、可被基准和硬件双重验证的
> 汉字结构知识基座；遗产轨隔离标记，不洗白、不删除。

**非目标（不变）**：不写 OS、不商业化、不做 JEPA 新实验、不碰 97,686 扩展字表、
不在标准文本到手前批量改数据。

## 3. 工作流（WS-4 … WS-9）

### WS-4 基准评测 v0.1（原计划 WS-4，修订）

- 内容：定义并落地"汉字结构理解"基准的最小可用版——以 8105 标准轨 7,310 行为金标，
  任务 = 结构分类（13 类）/ 部首识别 / 笔画数预测。
- 基线：至少 2 个开源模型 + CNBE 特征注入对比；指标 = 准确率 + 分歧分析。
- 与 WS-5 的纪律：**预注册 commit 必须先于结果 commit**。
- 交付：`benchmarks/` 目录 + 评测脚本 + 预注册文档。
- 依赖：PR #40（导出管线）合入。
- 工期估计：2–3 周。

### WS-5 消融预实验（原计划 WS-5，不变）

- 内容：按已入库的消融设计方案跑预实验（结构信息增益、部首锚定增益、笔画监督增益）。
- 纪律：预注册 → 跑数 → 结果 → 报告，四步分离留痕。
- 依赖：WS-4。
- 工期估计：2 周。

### WS-6 编码与硬件 C 基线（原计划 WS-6，修订）

- 内容：冻结后字段的物理编码协议（含 strokes>31 的溢出表示、block_offset 寻址、
  双编号清理后的 struct_type 4-bit 编码）+ RISC-V 软核上的 C 参考实现与正确性测试。
- 边界：只做编解码正确性与吞吐基线，不做性能优化。
- 依赖：WS-3 冻结规范合入；电子科大验证合作（A5）在此衔接（当前不作为前置依赖）。
- 工期估计：3–4 周。

### WS-7（新）8105 标准轨闭环

- 内容：
  1. 276 个 8105 缺失字补录（A4）；
  2. WS-2 队列 767 行裁决执行（P1×37 / P2×727 / P3×3）；
  3. 8105 内 511 行笔画分歧 + 430 行 strokes=31 错值按 GF 0013 修复。
- 关键约束：A1–A3 原依赖北语输入；**已裁决按可执行子集推进** =
  用 Unihan + IDS 双源一致的行先行修复（证据等级如实标注），双源分歧行挂起。
- 交付：迁移脚本（带 dry-run + 回滚）、迁移前后证据 diff 报告。
- 工期估计：可执行子集 2 周；标准级闭环待权威来源到位。

### WS-8（新）遗产轨隔离

- 内容：英文轨 12,529 行 + triangle 1,026 行（8105 外）打 `track=legacy` 标记、
  从默认导出中隔离；**已裁决：只隔离不重标**（D3 方案 a）。
- 交付：迁移脚本 + 导出管线 track 过滤选项。
- 工期估计：1 周。

### WS-9（新）v1.1.0 发版

- 内容：WS-4…WS-8 全部合入后一次性发版；发版说明如实标注：标准轨覆盖率、
  裁决闭环率、基准结果、硬件基线结果、遗产轨隔离状态。
- 依赖：全部前置 WS + 治理批准。

## 5. 决策记录（已裁决）

### D1 三个 PR 的合并节奏 → 采纳方案 a

#40 → #41 → #42 顺序合入（2026-07-25 完成）。三者文件集不相交，无冲突。

### D2 WS-7"双源一致先行修复"→ 授权

对 Unihan 与 IDS **一致**的行先行修复；双源分歧行挂起。迁移记录与发版说明中
证据等级如实标注（交叉参考源双确认，非标准）；标准文本到手后全量复核。

### D3 遗产轨（13,555 行）→ 采纳方案 a：只隔离不重标

理由：8105 标准轨闭环已是第二阶段满负荷；AI 预标回流的方法论风险不可接受
（这正是项目批评别人的做法）。

### D4 WS-4 基准的模型基线选择 → 待 WS-4 预注册时裁决

建议：2 个可本地复现的开源模型（避免 API 漂移）+ CNBE 特征注入对比。

## 7. 本 PDR 与长期叙事的关系

- 第二阶段结束时，项目将拥有：**语义冻结的数据层 + 外部可复现的基准 + 硬件参考实现**——
  这是"让 AI 可靠识别汉字结构"主张的最小可信证据链，也是面向 2035 数字中国叙事的
  第一个可交付里程碑。
- 北语（汉字学验证）与电子科大（RISC-V 验证）在第二阶段是**可选加速项**而非依赖：
  到位则闭环升级为标准级，不到位则按可执行子集推进，合作谈判与工程落地解耦。
