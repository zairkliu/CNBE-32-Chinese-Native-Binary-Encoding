## 二、非中文干扰处理

1. 整体 CNBE 覆盖率 78.33%，低的原因是标点、西文、数字和未知字符；
2. CJK-only 覆盖率 99.999%，说明中文汉字本身覆盖完整；
3. 训练主数据建议只使用 core_chinese_subset；
4. 技术子集单独保留，供代码/术语类任务；
5. 后续 Structure-MLM 前需过滤或单独标注 code 0。

## 三、出版信息清理规则

v2 清洗新增/强化规则：

- 删除 YAML frontmatter；
- 删除版权页、CIP、ISBN、书号、出版社、电子版制作信息；
- 删除“总目录”整块与书名/作者/译者/编者/主编行；
- 删除通讯地址、邮编、电话、邮箱、开本、印张、定价；
- 删除理想国译丛序、丛书总序、出版说明、编辑推荐、内容提要、
  作者简介等前页整块；
- 删除图片、目录链接、脚注、HTML/CSS、页码、`[TABLE]`；
- 书名页标题后出现著/译/出版社/ISBN/版权时跳过该标题；
- Markdown 标题与引用符转为纯文本。

## 四、打包方式

一键重建脚本：

```bash
python repo/tools/build_corpus_version.py \
  --md-dir "D:\训练语料\新书目录" \
  --version v3 \
  --work-dir "D:\训练语料" \
  --db repo/data/cnbe32.db
```

脚本会依次执行：

```text
清洗 -> CNBE 编码 -> 子集划分 -> CJK 覆盖率 ->
minhash 去重 -> 合并既有 24M -> 重建 vocab/mapping
```

```text

```

## 六、加入 3000+ 本新书的计划

### 1. 输入准备

- 把新书 MD 放到统一目录或 zip；
- 每个文件保留书名可识别文件名，转换器元数据可留在 frontmatter；
- 不建议直接合并进既有目录，避免覆盖版本。

### 2. 执行

```bash
python repo/tools/build_corpus_version.py \
  --md-dir "D:\训练语料\新书3000" \
  --version v3 \
  --work-dir "D:\训练语料"
```

### 3. 质量门槛

| 门槛 | 要求 |
|---|---|
| 中文占比 | 核心子集 ≥70%，技术子集 30%-70% |
| CJK-only 覆盖率 | ≥99.9% |
| minhash 去重 | 阈值 0.7，新增精确重复需处理 |
| 抽样复核 | 每类至少 5 本 |
| 出版信息 | 抽查不应再出现版权页/CIP/总目录 |

### 4. 规模估算

当前 1,281 本平均约 41.5 万字符/本：

- 3,000 本约新增 12.5 亿字符；
- 合并后总规模约 17-18 亿字符；
- 按 4096 token/step 估算，1 epoch 约 42-44 万步；
- 双卡 BW 约 1.93 steps/s，单 epoch 约 60-63 小时；
- 建议届时增大 batch 或使用多节点，或先按核心子集训练。

### 5. 磁盘估算

- 清洗文本：约 5GB；
- CNBE 码流：约 6GB；
- 合并 assets：约 0.5GB；
- 上传包：约 4-5GB。

## 七、执行顺序

1. 收集并整理 3000+ 新书 MD；
2. 跑 `build_corpus_version.py --version v3`；
3. 查看 excluded 与低覆盖率警告，人工复核；
4. 更新 `prepare_merged_dcu_package.py` 路径并打包 v3；
5. 上传云训练：先 smoke，再 Dense/Unicode 对照，再 128 专家。
