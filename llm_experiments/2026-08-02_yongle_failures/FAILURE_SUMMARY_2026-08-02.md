# 今日失败结果总结（2026-08-02）

## 1. 一句话结论

1.5B 生成式模型无法胜任“400-500 字整页 OCR 转录 + 排版重排”；今日所有失败
共同指向同一个结论：**LLM 不做转录，只做真值之上的结构加工（句读与分段）**。

## 2. 今日实验证据

### 2.1 OCR 识别覆盖率（《永乐大典》卷821-823“诗字”，37 页人工校订为真值）

| 引擎 | 识别字数 | 覆盖率 | 精确率 |
|---|---:|---:|---:|
| PaddleOCR PP-OCRv4 | 11,654 | 18.05% | 24.97% |
| DeepSeek-OCR v1（去重后） | 18,759 | 37.76% | 32.45% |
| v1 / Paddle 逐页择优 | - | 38.79% | - |
| DeepSeek-OCR-2 | 连续多页空返回 | 不可用 | 不可用 |

### 2.2 1.5B 生成式整页修正

| 版本 | 训练 | 结果 |
|---|---|---:|
| v3 聊天模板 | 600 步 | 约 21.27% |
| v4 原始续写 | 1,000 步 | 约 20.31% |

长目标序列训练中 Eval Loss 可升至 9.9，模型开始乱猜与重复，无法完成
400-500 字整页转录。

### 2.3 成功的对照实验

- 页面锚定人工校订库：37 页命中率 100%，score=1.0。
- 识典古籍公开《诗话六十三》与本项目人工校订逐字一致：16,082/16,082，
  覆盖率 100%，相似度 1.0000。
- 大字标题多候选检索：演示命中 0.974。

## 3. 根因分析

1. **任务错配**：整页精确转录属于序列转录（Sequence Transcription），
   不是 LLM 的生成强项；1.5B 在 400 字以上目标上失去位置记忆。
2. **输入脏数据**：模型接收 PaddleOCR 乱序文本，把版面错误和字形错误混在一起，
   模型无法区分。
3. **推理模式干扰**：聊天模板/思考模式会吐出 think 标签，降低输出可用性。
4. **数据形态错误**：整页样本过长，小模型上下文退化；应使用 80-150 字短样本。

## 4. 今日教训清单

| # | 教训 | 落地规则 |
|---|---|---|
| 1 | 不要用 1.5B 修 OCR 整页错误 | 转录交给 OCR + 真值库 |
| 2 | 真值优先，OCR 只做定位 | 大字锚点 + page_hint 命中即 100% |
| 3 | 阅读顺序是几何问题 | 分栏/排序用坐标规则，不训 LLM |
| 4 | LLM 的舒适区是短文本句读 | 80-150 字片段，不做整页生成 |
| 5 | 关闭思考模式 | 纯文本续写，无 think 标签 |
| 6 | 编码知识不能遗忘 | 在原有 CNBE 模型/数据上继续，混入 CNBE 样本 |
| 7 | 14B 才有资格做高质量句读 | 用今日全部失败教训训练 DeepSeek-R1-Distill-Qwen-14B |
