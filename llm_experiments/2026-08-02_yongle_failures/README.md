# 2026-08-02 永乐大典失败实验

本目录沉淀 2026-08-02《永乐大典》OCR 失败实验的结果与教训。

## 核心结论

1. 1.5B 无法完成 400-500 字整页 OCR 转录（精确匹配约 20%）；
2. OCR 只做定位与兜底；页面锚定真值库命中率 100%；
3. 识典公开文本与人工校订逐字一致 100%；
4. LLM 重新定位为“真值之上的古籍句读与分段”。
