## 一、失败实验（OCR）

《永乐大典》卷 821-823“诗字”37 页人工校订实验确认：

- PaddleOCR 覆盖 18.05%、精确 24.97%；
- DeepSeek-OCR v1 去重后覆盖 37.76%、精确 32.45%；
- DeepSeek-OCR-2 连续多页空返回，不可用；
- 1.5B 生成式整页修正：v3 精确匹配 21.27%，v4 为 20.31%；
  长目标训练 Eval Loss 可升至 9.9，模型开始乱猜与重复；
- 页面锚定人工校订真值库命中率 100%，识典古籍公开文本逐字一致 100%；
- 结论：1.5B 不做整页转录，LLM 只做真值之上的句读与分段。

结论：

1. gzip 仍是最优纯压缩；CNBE 差距 +7% 到 +20%，OCR 噪声越大差距越大；
2. CNBE Volume 提供 O(1) 随机定位（seek 约 0.001 ms）与结构化检索；
3. CNBE-MoE 路由 FLOPs 加速恒等于 E/m，16 专家负载近似完全均衡；
4. 路由代理准确率 74%-84%，远高于线性路由 6%-8%，但需真实 MoE 训练验证；
5. DeepSeek V4 API 可复现句读，专家编号一致性不能作为标签来源。
