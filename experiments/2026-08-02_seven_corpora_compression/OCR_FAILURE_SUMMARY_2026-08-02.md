# 2026-08-02 OCR 失败实验简明总结

## 实验背景

以《永乐大典》卷 821-823“诗字”37 页人工校订文本为真值，验证
“OCR + 小模型整页纠正”路线。

## 关键数据

| 引擎/方案 | 覆盖/精确 | 结论 |
|---|---|---|
| PaddleOCR PP-OCRv4 | 18.05% / 24.97% | 单字可用，版面顺序错误 |
| DeepSeek-OCR v1（去重后） | 37.76% / 32.45% | 长文本重复严重 |
| DeepSeek-OCR-2 | 连续多页空返回 | 本地不可用 |
| 1.5B v3 整页修正 | 精确匹配 21.27% | 不可用 |
| 1.5B v4 整页修正 | 精确匹配 20.31% | 不可用 |
| 页面锚定人工校订库 | 命中 100% | 可用 |
| 识典古籍公开文本交叉验证 | 16,082/16,082，相似度 1.0 | 可用 |

长目标训练中 Eval Loss 可升至 9.9，模型开始乱猜与重复，无法完成
400-500 字整页转录。

## 根因

1. 任务错配：整页精确转录是序列转录，不是 1.5B 模型的生成强项；
2. 输入脏数据：OCR 版面错误与字形错误混在一起，模型无法区分；
3. 推理模式干扰：chat/think 模板消耗输出预算；
4. 数据形态错误：整页样本过长，小模型上下文退化。

## 转向

- 真值优先：OCR 只做定位与兜底，页面命中真值库后直接返回 100% 正确文本；
- LLM 只做短文本句读与分段（80-150 字片段）；
- 用今日全部失败教训训练 DeepSeek-R1-Distill-Qwen-14B 句读模型；
- 完整复盘、白皮书与 14B 配置见
  [`../../llm_experiments/2026-08-02_yongle_failures/`](../../llm_experiments/2026-08-02_yongle_failures/README.md)。
