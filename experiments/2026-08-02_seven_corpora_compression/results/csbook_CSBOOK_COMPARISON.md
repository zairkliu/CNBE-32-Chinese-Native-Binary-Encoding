## 6. 结论

四轮语料覆盖古文、白话、翻译小说、技术文档，定性结论全部一致：

1. gzip 纯压缩最优；CNBE 差距随语料结构集中度缩小（+13.5% -> +7.2%）。
2. CNBE Volume 的 O(1) 随机访问与结构化检索在所有语料上成立。
3. CNBE-MoE FLOPs 加速恒等于 E/m，16 专家负载近似均衡。
4. DeepSeek V4 API 复现稳定；句读 F1 随语体波动，专家编号一致性与
   结构字段分类仍为弱代理指标。
