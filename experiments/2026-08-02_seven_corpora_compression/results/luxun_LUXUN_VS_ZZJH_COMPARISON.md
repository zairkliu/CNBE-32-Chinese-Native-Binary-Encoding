## 6. 结论

两套语料上所有实验的**定性结论完全一致**：

1. 纯压缩场景 gzip 仍优于 CNBE 定长/分页 zlib（约 +13.5% / +42%）。
2. CNBE Volume 提供 O(1) 随机定位、按页展开和结构化检索，代价是可接受的体积差。
3. CNBE-MoE 路由 FLOPs 加速严格等于 E/m，负载均衡由结构映射保证。
4. DeepSeek V4 API 可低成本复现大模型侧实验；专家编号一致性不能当质量指标，
   结构字段存在标注口径差，真实 MoE 下游仍需替换路由器验证。

定量差异（模板数、F1、检索耗时）来自语料构成（古文注疏 vs 现代白话小说），
不属于结论冲突。
