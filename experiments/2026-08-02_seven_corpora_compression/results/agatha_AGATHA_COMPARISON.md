## 6. 结论

三轮语料（古文注疏 / 现代白话 / 翻译小说）的定性结论完全一致：

1. gzip 仍是纯压缩最优，CNBE 定长/分页压缩约多 13%-47%。
2. CNBE Volume 提供 O(1) 随机定位与结构化检索，代价是略大的体积。
3. CNBE-MoE 路由 FLOPs 加速严格等于 E/m，16 专家负载接近完全均衡。
4. DeepSeek V4 API 可低成本复现大模型侧实验；句读 F1 随语体波动，
   专家编号一致性不能作为质量指标，结构字段存在标注口径差。

定量差异全部可由语料构成解释，不存在结论冲突。
