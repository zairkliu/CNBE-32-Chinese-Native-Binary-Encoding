# CNBE Volume 基准报告

- 数据：金庸作品全集（新修版，全36册），7,558,400 字
- 卷大小：14,728,662 B vs 原文 22,675,213 B（64.95%），vs gzip 10,489,072 B（140.42%）
- 页大小：4096

| 操作 | CNBE Volume | gzip 全文解压后读取 |
|---|---:|---:|
| seek(100000) | 0.001 ms | - |
| extract 100 字 | 0.020 ms | 62.421 ms（解压后切片） |
| random_passage(500) | 0.655 ms | - |
| search(radix=38, struct=1) | 255.156 ms | 不支持 |
| 全文流式扫描 | 1.594 s | 0.058 s（仅解压） |

## 说明

CNBE Volume 将整篇 gzip 解压时间分摊为按页 O(1) 解压；gzip 单次读
取需要先全文解压。结构化检索（部首/结构/笔画）为 CNBE Volume 独有能力。
