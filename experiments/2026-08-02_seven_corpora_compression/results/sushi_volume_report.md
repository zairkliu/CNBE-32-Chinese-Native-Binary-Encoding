# CNBE Volume 基准报告

- 数据：蘇文忠公詩集（宋集珍本丛刊）132 页，28,284 字
- 卷大小：31,575 B vs 原文 84,852 B（37.21%），vs gzip 22,425 B（140.80%）
- 页大小：4096

| 操作 | CNBE Volume | gzip 全文解压后读取 |
|---|---:|---:|
| seek(14142) | 0.001 ms | - |
| extract 100 字 | 0.020 ms | 0.120 ms（解压后切片） |
| random_passage(500) | 1.113 ms | - |
| search(radix=38, struct=1) | 1.496 ms | 不支持 |
| 全文流式扫描 | 0.002 s | 0.000 s（仅解压） |

## 说明

CNBE Volume 将整篇 gzip 解压时间分摊为按页 O(1) 解压；gzip 单次读
取需要先全文解压。结构化检索（部首/结构/笔画）为 CNBE Volume 独有能力。
