## 6. 结论

六轮语料（历史、文学、翻译小说、技术文档、武侠小说、现代杂志）的定性结论全部一致：

1. gzip 纯压缩最优，CNBE 差距 +7% 到 +14%，技术文档最接近。
2. CNBE Volume 提供 O(1) 随机访问与结构化检索，代价约 +40% 到 +47% 体积。
3. CNBE-MoE FLOPs 加速恒等于 E/m；16 专家负载近似完全均衡。
4. DeepSeek V4 API 可低成本复现大模型侧实验；句读 F1 随语料在 0.60-0.85 波动，
   专家编号一致性与结构字段分类仍为弱代理指标。

定量差异均可由语料构成解释，不存在结论冲突。
