# 蘇文忠公詩集 vs 前六轮语料

第七轮复现：古籍诗集语料《蘇文忠公詩集》（宋集珍本丛刊，DJVU 影印 132 页）。

## 0. 数据来源说明

该 DJVU 为扫描影印本，132 页中仅第 2 页带内嵌文本层（`djvutxt` 提取），其余页面使用
本地 Ollama `deepseek-ocr`（60dpi 渲染 + `OCR the image` 提示词）逐页识别。95 页产出
文本，37 页为插图/高密度批注页未能识别。最终语料 28,284 字，属于七轮中规模最小、
噪声最高的一轮。

## 6. 结论

七轮语料（历史、文学、翻译、技术、武侠、杂志、诗集）的定性结论全部一致：

1. gzip 纯压缩最优；CNBE 差距 +7% 到 +20%，OCR 噪声越大差距越大。
2. CNBE Volume 提供 O(1) 随机访问与结构化检索，代价约 +40% 到 +47% 体积。
3. CNBE-MoE FLOPs 加速恒等于 E/m；16 专家负载近似完全均衡。
4. DeepSeek V4 API 可低成本复现大模型侧实验；句读 F1 随语料质量在 0.48-0.85 波动。

定量差异全部可由语料构成与 OCR 噪声解释，不存在结论冲突。
