# CNBE Volume 基准报告

- 数据：鲁迅全集（2005版）18卷，3,864,304 字
- 卷大小：7,429,127 B vs 原文 11,592,912 B（64.08%），vs gzip 5,231,719 B（142.00%）
- 页大小：4096

| 操作 | CNBE Volume | gzip 全文解压后读取 |
|---|---:|---:|
| seek(100000) | 0.001 ms | - |
| extract 100 字 | 0.020 ms | 33.938 ms（解压后切片） |
| random_passage(500) | 0.651 ms | - |
| search(radix=38, struct=1) | 248.074 ms | 不支持 |
| 全文流式扫描 | 0.874 s | 0.032 s（仅解压） |

## 说明

CNBE Volume 将整篇 gzip 解压时间分摊为按页 O(1) 解压；gzip 单次读
取需要先全文解压。结构化检索（部首/结构/笔画）为 CNBE Volume 独有能力。
