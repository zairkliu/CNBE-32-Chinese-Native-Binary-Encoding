# CNBE Volume 基准报告

- 数据：阿加莎·克里斯蒂全集（人民文学版），7,804,198 字
- 卷大小：14,346,605 B vs 原文 23,412,594 B（61.28%），vs gzip 9,787,236 B（146.58%）
- 页大小：4096

| 操作 | CNBE Volume | gzip 全文解压后读取 |
|---|---:|---:|
| seek(100000) | 0.001 ms | - |
| extract 100 字 | 0.020 ms | 55.492 ms（解压后切片） |
| random_passage(500) | 0.637 ms | - |
| search(radix=38, struct=1) | 446.048 ms | 不支持 |
| 全文流式扫描 | 1.773 s | 0.056 s（仅解压） |

## 说明

CNBE Volume 将整篇 gzip 解压时间分摊为按页 O(1) 解压；gzip 单次读
取需要先全文解压。结构化检索（部首/结构/笔画）为 CNBE Volume 独有能力。
