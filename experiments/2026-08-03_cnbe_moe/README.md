## 二、核心结果

### 2.1 小型 MoE 实证（6M 字 / 1200 步 / d384）

| 模型 | Next-code 准确率 | 训练期 Gini | 说明 |
|---|---:|---:|---|
| Dense | 15.92% | - | 基线 |
| MoE-8 | 17.65% | 0.030 | 均衡 |
| MoE-16 | 17.99% | 0.162 | 预置映射在多语料上略失衡 |
| MoE-64 | 19.18% | 0.297 | 质量最高，负载失衡 |
| MoE-64-3f（三字段映射） | 18.98% | **0.153** | 当前推荐配置 |

### 2.2 Triton grouped GEMM kernel

- 前向/反向一致性误差约 1e-7；
- 当前小模型规模下 Triton 未超过向量化 bmm（4.02 vs 9.02 steps/s），
  需更大规模/persistent kernel 才能体现收益。

### 2.3 学习式路由

- Switch 均衡损失把 Gini 从 0.78 降到 0.48，但仍高于三字段硬映射；
- 当前推荐：硬 CNBE 查表 + 三字段均衡映射。

### 2.4 DeepSeek V4 API 消融

| 任务 | 原文 | CNBE 提示 | Unicode 提示 |
|---|---:|---:|---:|
| 句读 F1 | **0.8472** | 0.8348 | 0.6544 |
| 形近字纠正准确率 | 0.6000 | **0.9333** | 0.7667 |

结论：CNBE 结构字段对字符级消歧收益显著，对句读等语言生成任务无增益。

## 三、下一步

1. 以“64 专家三字段硬路由”为 A100 训练默认配置；
2. 字符级任务（消歧/路由）走 CNBE 结构字段，语言级任务走普通文本；
3. 更大模型与 persistent Triton kernel 的收益验证。
