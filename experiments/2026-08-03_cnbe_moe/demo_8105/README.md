# CNBE-32 8105 规范汉字演示程序（Windows 11）

基于 GitHub 仓库 `src/cnbe32_demo` 的桌面演示，聚焦 8105 通用规范汉字表。

## 运行

1. 安装 Windows 64 位 Python 3.10+（勾选 Add python.exe to PATH）；
2. 双击 `run_demo.bat`。

## 功能

- 编码查询：输入汉字，逐字输出 Unicode、CNBE-32 十六进制/32 位二进制、
  部首/笔画/结构/索引/扩展位与轨道状态；
- 8105 规范汉字表：浏览标准轨已编码记录，支持按汉字、部首编号、
  笔画数或部首名筛选；
- 复制结果：一键复制详情文本。

## 说明

- 程序自包含 `cnbe32` 包与运行时数据库，不依赖 GitHub 仓库路径；
- CNBE-32 不替代 Unicode，标准轨为项目对齐基线，不代表国家标准认证。
