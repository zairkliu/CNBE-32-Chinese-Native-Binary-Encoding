# CNBE-32 数学模型深化实验报告（2026-08-05）

**环境**：Ubuntu-26.04 WSL  
**数据**：`data/cnbe32.db`，21,178 行真实运行时记录  
**锚点**：v8 五层模拟器全部 PASS + Linux 0.01 CNBE-32 RISC-V 内核在 QEMU/OpenSBI 下启动成功

---

## 一、项目情况定义

当前 CNBE-32 已不是“编码方案演示”，而是具备三层实证锚点的工程与理论基座：

1. **语义锚点**：`cnbe.cmp` 与字段提取在 Python / C / QEMU / Verilog / Spike 五层实现中一致；
2. **系统锚点**：中文编码运行时已编译进 RISC-V 内核，并在 QEMU 中启动输出中文系统信息；
3. **数据锚点**：所有数学实验基于同一份 21,178 行真实数据库，不依赖合成表。

因此，本轮实验的目标是回答：这些数学深化方向是否成立、边界在哪里、哪些可以立刻工程化。

## 二、方向一：公理化度量空间

**实验**：20 万对随机样本验证非负性/对称性/三角不等式；21,178 行全量统计同一性。

| 公理 | 结果 |
|---|---|
| 非负性 | PASS |
| 对称性 | PASS |
| 三角不等式 | PASS（20 万组，0 反例；线性加权 L1 距离理论上恒成立） |
| 同一性 D(c₁, c₂) = 0 ⟺ c₁ = c₂ | **FAIL** |

**关键发现**：`cnbe.cmp` 忽略 `idx/ext`，因此不同码只要 `radix/stroke/struct` 相同，距离就是 0。全库存在 **50,728 对不同码零距离**。

**结论**：

- `cnbe.cmp` 是 **伪度量（pseudo-metric）**，不是严格度量；
- 若要成为度量，需二选一：
  1. 在码空间上按 `(radix, stroke, struct)` 定义等价类，`cmp` 对等价类成立；
  2. 在距离中引入 `idx` 或最小非零扰动项。
- 伪度量本身不一定是缺陷；对形近字消歧，忽略 `idx/ext` 反而符合“结构相同即零距离”的语义。

## 三、方向二：格论与偏序集

**实验**：在 ℕ³（部首/笔画/结构）上验证分配格四律，并实现三维前缀和范围查询。

| 指标 | 结果 |
|---|---|
| 不同三元组 | 15,382 |
| 幂等律 / 交换律 / 结合律 / 吸收律 | 全部 PASS |
| 范围查询 1000 次 | 前缀和 0.0016s vs 暴力 2.41s |
| 加速比 | **1500x** |
| 结果一致性 | 1000/1000 一致 |

**结论**：

- 逐字段分量序构成分配格，数学结构成立；
- 3D 前缀和范围查询是 O(1)，可直接用于“同部首、同结构、笔画范围”的结构检索；
- `cnbe.skill` 精确反查不需要遍历 21k 表，用哈希表即可 O(1)；格结构更适合范围查询与最近公共属性查询。

## 四、方向三：信息论熵分析

**实验**：基于真实字段分布计算熵与互信息。

| 量 | 值 |
|---|---:|
| H(radix) | 7.5086 bit |
| H(stroke) | 4.8317 bit |
| H(struct) | 3.3792 bit |
| H(radix,stroke,struct) | 13.2833 bit |
| H(stroke \| radix) | 4.5803 bit |
| I(radix;stroke) | 0.2514 bit |
| 字段容量（8 + 5 + 4 位） | 17 bit |
| 冗余 | 3.7167 bit |

**结论**：

- 当前 8/5/4 分配不是熵最优：联合熵 13.28 bit，冗余约 3.72 bit；
- `H(stroke|radix)=4.58` 说明笔画并不能由部首强预测，不能简单缩减笔画位宽；
- `I(radix;stroke)=0.25` 说明两者近乎独立；
- 若做“自适应 CNBE”，理论压缩空间约 3.7 bit/字，但会牺牲固定位宽的结构可计算性；建议把熵分析用于存储层设计，不改变 RISC-V 字段语义。

## 五、方向四：双曲几何嵌入

**实验**：将三元组归一化到庞加莱球半径 0.9，计算双曲距离与线性距离的秩相关。

| 指标 | 值 |
|---|---:|
| 同部首双曲距离均值 | 2.3018 |
| 跨部首双曲距离均值 | 3.1190 |
| 部首分离比 | 1.3551 |
| 与加权距离的 Spearman 相关 | 0.4029 |

**结论**：

- 双曲距离是有限、可计算的，且能拉开同部首/跨部首距离；
- 但与现有加权距离只有约 0.40 秩相关，说明它不是简单单调变换；
- **没有已标注的形近字评测集，不能声称 92.7% → 95%**；该方向需要先建立与 API 消融一致的评测集，再判断是否有效。

## 六、方向五：代数规范与性质测试

**实验**：对 `map/extract/cmp/skill` 进行轻量代数公理性质测试。

| 公理 | 结果 |
|---|---|
| extract(map(U), field) = field(U) | PASS |
| cmp 非负、对称 | PASS |
| cmp 三角不等式 | PASS |
| skill(map(U)) 返回首个匹配 | PASS |
| 总断言 | 160,000 PASS / 0 FAIL |

**结论**：

- 现有 C/Python/Spike/Verilog 与真实 DB 满足这组轻量代数性质；
- 下一步若冲击 CAV/PLDI 级形式化，应把这些公理写成 TLA+ 或 Coq，并用 CBMC/SymbiYosys 做实现级验证。

## 七、明确结论

| 方向 | 结论 | 建议 |
|---|---|---|
| 公理化度量 | 伪度量成立；同一性不成立 | 明确“结构等价类”语义，不改 RISC-V 字段 |
| 格论 / 范围查询 | 成立且工程价值明确 | 采纳；用于结构范围检索与硬件索引设计 |
| 信息论 | 存在 3.7 bit 冗余 | 采纳为存储层研究，不改变编码语义 |
| 双曲几何 | 数学上可计算，无任务级证据 | 暂不采信 95% 承诺；先建形近字评测集 |
| 代数规范 | 性质测试全过 | 可作为形式化验证的前置证据 |

**一句话总结**：CNBE-32 的数学模型已经具备真实数据、五层模拟器和可启动内核三个锚点；本轮确认格论与范围查询可立即工程化，熵分析适合存储层，度量必须承认伪度量边界，双曲几何需要评测集，形式化验证应从轻量性质测试升级为 TLA+/Coq。

## 八、深度分析结果（二次深化）

### 8.1 度量等价类

按 `(radix, stroke, struct)` 分组后：

| 指标 | 值 |
|---|---:|
| 不同三元组 | 15,382 |
| 多字三元组类别 | 1,093 |
| 位于多字三元组中的行数 | 6,889 |
| 全库占比 | 32.5% |

这说明伪度量不是偶发：约三分之一行共享同一三元组，`cmp` 必须明确“结构等价类”语义。

若将 `idx/ext` 以权重 1 加入距离，三角不等式在 20 万组上仍成立，且零距离等价类消失。

### 8.2 格与范围查询深化

- 分配律（双分配恒等式）在 10 万组随机三元组上成立；
- 真实三元组的 join / meet 闭合率分别约为 41.3% / 45.3%，说明“格操作结果不一定落在现有字表内”，范围查询应基于分量界而不是闭合集合；
- 3D 前缀和范围查询保持 O(1)，是结构检索的推荐索引。

### 8.3 信息论深化

| 量 | 值 |
|---|---:|
| H(code) | 14.3699 bit |
| H(tuple) | 13.2833 bit |
| Huffman 平均码长 | 13.3498 bit |
| 固定 17 bit 冗余 | 约 3.7 bit |
| I(radix;stroke) | 0.2514 bit |
| I(radix;struct) | 0.4013 bit |
| I(stroke;struct) | 1.6024 bit |

结论：

- `stroke-struct` 互信息明显更高，说明结构类型与笔画分布存在统计关联；
- Huffman 估计说明在不牺牲可计算结构的前提下，存储层理论最优约 13.35 bit/字；
- 固定字段语义仍是 RISC-V/MoE 侧的正确选择，熵优化留给存储层。

### 8.4 几何判别能力（AUC 与 kNN）

以“同部首/跨部首”作为结构相似性代理：

| 距离 | 同部首 AUC | 1-NN 部首准确率 |
|---|---:|---:|
| CNBE 加权 | 0.9845 | 0.450 |
| 欧氏 | 0.9639 | 0.264 |
| 双曲 | 0.7092 | 0.018 |

结论：

- 加权距离在“部首判别”代理任务上最强；
- **双曲距离在现有代理任务上明显更差**，不能支持“双曲能提升形近字 92.7%→95%”的假设；
- 若仍想研究双曲，必须用与 API 消融一致的形近字标注集，而不是结构性代理。

### 8.5 全量代数性质

| 公理 | 检查量 | 通过 |
|---|---|---:|
| extract(map(U), field) = field(U) | 105,890 | 105,890 |
| cmp 非负/对称 | 500,000 | 500,000 |
| cmp 三角不等式 | 500,000 | 500,000 |
| skill(map(U)) 首个匹配 | 21,178 | 21,178 |
| 哈希反查 = 线性反查 | 10,000 | 10,000 |

所有代数性质全过；下一步才适合进入 TLA+/Coq + CBMC/SymbiYosys 的形式化证明阶段。

### 8.6 最终判断

- **采纳**：格/范围查询、信息论存储优化、度量等价类语义、代数性质测试；
- **暂缓**：双曲几何作为 CNBE 相似度的主距离，因为代理评测显著差于线性加权；
- **可继续**：建立形近字标注集后，再对双曲/欧氏/加权做公平评测。
