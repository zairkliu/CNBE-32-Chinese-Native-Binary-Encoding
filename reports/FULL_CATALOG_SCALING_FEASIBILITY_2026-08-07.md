- 确定性证据层可覆盖 89.56% 行（87,485/97,686），零 API 成本；

## 人工审核工作量

97,686 行逐字人工审核不可行（按 2 分钟/字约 407 个工作日）。建议分层：

| 层 | 范围 | 审核方式 | 预估 |

| Medium | 确定性完整未 LLM 确认 | 抽样复核 + 冲突回查 | 2-4 天 |

## 风险

- 扩展字证据覆盖率低于 8105，LLM 严格一致率仅 70%（20 条抽样）；
- 172 字笔画超过 31，CNBE32 无法直接编码，需 CNBE64/扩展位；
- GB 18030 双向映射仍缺失；
- API 价格与限流未固化，全量 LLM 前应先跑 300 字试点并确认成本上限；
- 全量候选库必须保持独立，不替换 `data/cnbe32.db`。

## 推荐路线

1. 完成 8105 legacy 491 人工审核，形成首个预填一致性基准；
2. 执行既有 300 字全量试点，把 LLM 一致率基线从 70% 扩大到 300 条；
3. 免费跑全量证据层，锁定 10,201 不完整行清单；
4. LLM 只跑不完整行 + QA 抽样，预算由 `pipeline_config.json` 守卫；
5. 分层人工审核后进入隔离候选库构建，治理授权前不写 SDK 库。
